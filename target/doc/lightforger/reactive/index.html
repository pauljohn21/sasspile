Reactive compilation pipeline.

Module layout:

  • bus.rs: CompilerBus with multicast subjects
  • types.rs: Core types (EvalContext, Value, CssStmt, SassOp trait)
  • ext.rs: Observable extension combinators (placeholder, task 3.1)
  • ops/: One module per SassOp directive
  • pipeline/: Lexer / Parser / Evaluator / Serializer stages
